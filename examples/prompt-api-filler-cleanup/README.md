# 書き起こしのフィラー除去

音声を書き起こしたテキストから、「えーと」「あの」「まあ」のようなフィラー（言い淀み）だけをPrompt API（`LanguageModel`）に取り除かせるサンプルです。

2段階のパイプライン構成になっています。「録音後に自動でフィラー除去まで実行する」（既定でオン）にチェックが入っていると、録音から除去まで自動で続けて実行されます。オフにすると、書き起こし後に「フィラーを除去する」ボタンを押すまで待機します。

1. **書き起こし**: マイクで5秒録音し、[音声を文字起こしする](../prompt-api-audio/)と同じ方法で音声を直接Prompt APIに渡します。`promptStreaming()`で受け取った断片をそのつどテキストエリアに追記するので、書き起こし中の文章がリアルタイムに増えていく様子を確認できます。テキストを直接貼り付けても構いません。
2. **フィラー除去**: 書き起こしテキストを別のセッションに渡し、`promptStreaming()`で整形後の文章をストリーミング表示します。ストリーミング中はJSON Schemaによる構造化出力を使えないため、除去後の文章が出そろってから、同じセッションに「直前の整形で何を取り除いたか」を尋ね、`responseConstraint`で`{ removedFillers }`という配列だけを構造化出力として受け取ります。同じセッションで尋ねることで、直前のやり取りを文脈として使えます。

## 動かし方

Chrome 148以降で、このディレクトリを静的サーバーで配信して開いてください。

```bash
npx serve .
```

このサンプルの背景にある仕組みは [Prompt API入門](../../src/prompt-api.md) で解説しています。
